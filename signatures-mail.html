Où la coller

  1. Webmail Gandi : Réglages (la roue dentée) → Identités ou Signature → coller dans le champ, en veillant à ce que l'éditeur soit en mode texte enrichi et non en texte brut. Enregistrer.
  2. Mail sur Mac : Mail → Réglages → Signatures → créer une signature, décocher « Toujours utiliser la police par défaut », puis coller.
  3. iPhone : Réglages → Applications → Mail → Signature. Coller. Le format riche passe si la copie vient du navigateur.
  4. Outlook : Fichier → Options → Courrier → Signatures → coller.

Si la mise en forme se perd, c'est que l'éditeur est en texte brut : cherchez l'option « HTML » ou « texte enrichi » avant de coller.
