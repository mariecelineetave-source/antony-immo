Où la coller dans Proton Mail

  1. Vérifiez d'abord le format de rédaction : Paramètres → Toutes les paramètres → Rédaction (ou « Composer ») → Format par défaut : Normal. En « Texte brut », toute mise en forme est perdue à la première frappe.
  2. Paramètres → Toutes les paramètres → Identité et adresses.
  3. En face de marieceline.expertise@idf.immo, Modifier.
  4. Champ Nom d'affichage : écrivez exactement Marie-Céline Etave | Expertise IDF. C'est ce que vos destinataires voient en tête de leur boîte de réception — le nom d'abord, la marque ensuite.
  5. Activez la Signature, cliquez dans le champ, puis collez (Ctrl+V, ou ⌘+V sur Mac).
  6. Enregistrer. Envoyez-vous un courriel d'essai pour vérifier.

Si la mise en forme se perd au collage, c'est que l'éditeur est en texte brut : reprenez l'étape 1. Si vous avez plusieurs adresses Proton, la signature se règle adresse par adresse.

Ailleurs

  • Mail sur Mac : Mail → Réglages → Signatures → créer une signature, décocher « Toujours utiliser la police par défaut », puis coller.
  • iPhone : Réglages → Applications → Mail → Signature. Le format riche passe si la copie vient du navigateur.
  • Outlook : Fichier → Options → Courrier → Signatures → coller.
  • Webmail Gandi : Réglages → Identités ou Signature → coller, en mode texte enrichi.

Deux choses à savoir

  • Les images sont souvent bloquées. Beaucoup de messageries ne chargent pas les images d'un expéditeur inconnu au premier courriel : le logo et le portrait apparaissent alors vides. Tout le texte, lui, reste lisible — c'est pour cela qu'aucune information n'est écrite dans une image.
  • Le pictogramme téléphone du site n'est pas repris ici. C'est un dessin vectoriel (SVG), et les messageries le suppriment. La mention « Tél. » devant le numéro joue le même rôle : elle dit que 07. 656. 75007 est un numéro de téléphone.
