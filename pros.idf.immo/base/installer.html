Installer la base

Un bouton pour copier, huit clics pour coller. À faire une seule fois.

Étape 1 — Copier le script

Appuie sur ce bouton. Tout le script part dans le presse-papiers d'un seul coup, il n'y a rien à sélectionner.

Étape 2 — Le coller dans Supabase

  1. Ouvre supabase.com et ton projet pros-idf-immo.
    Le bouton en haut de cette page t'y emmène directement.
  2. Dans la colonne de gauche, clique sur l'icône >_
    C'est le « SQL Editor ». Elle ressemble à un petit écran noir, vers le haut de la colonne.
  3. Clique sur « New query »
    Ou sur le bouton +. Un grand cadre vide s'ouvre.
  4. Appuie longuement dans le grand cadre vide, puis « Coller »
    Le script apparaît. Il est long, c'est normal.
  5. Clique sur « Run »
    Le bouton vert, en bas à droite du cadre.
✓ Ce que tu dois voir

Un bandeau vert avec écrit Success. No rows returned.

C'est le message normal : ce script crée des tables, il ne renvoie donc aucun résultat à afficher. La base est installée.

Si tu vois du rouge : ne recommence pas, et ne modifie rien. Fais-moi une capture du message d'erreur, je corrige et je te redonne un bouton.

Le script est conçu pour être relancé sans dégât : le rejouer ne crée jamais de doublon et n'efface rien.

Étape 3 — Te déclarer administratrice

Cette seconde commande te donne accès au back-office. Elle ne fonctionnera qu'après ta première connexion au site avec contact@idf.immo — sinon elle ne trouvera personne à qui donner les droits.

Garde-la de côté : je te dirai quand la lancer.

Étape 4 — Me le dire

Écris-moi « la base est installée ». Je vérifierai de mon côté que les tables répondent, et je brancherai les écrans dessus.
